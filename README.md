# 하루 — 설치 안내

루틴·습관, 할 일, 일정, 목표, 가계부, 통계를 한 화면에서 쓰는 개인 기록 앱입니다.
파일 몇 개짜리 웹앱이라, 인터넷에 한 번 올려 두면 폰과 컴퓨터에서 같은 주소로 평생 쓸 수 있습니다.

**처음 설치하시나요? → `SETUP.md` 를 보세요.** 파일 받기부터 알림 받기까지 한 단계씩 적어뒀습니다.

## 폴더에 들어 있는 것

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체. 모든 화면과 기능이 여기 들어 있습니다 |
| `manifest.webmanifest` | 앱 이름·아이콘·시작 화면 설정 |
| `sw.js` | 오프라인 실행 + 알림 수신 |
| `keygen.html` | 알림 열쇠를 만드는 페이지 |
| `worker.js` | 알림 서버 코드 (클라우드플레어에 붙여넣음) |
| `SETUP.md` | 처음부터 끝까지 설치 순서 |
| `icon-192.png` / `icon-512.png` / `icon-maskable.png` / `apple-touch-icon.png` | 홈 화면 아이콘 |

파일 이름과 폴더 구조는 그대로 두세요. 이름을 바꾸면 서로를 못 찾습니다.

## 1단계 — 인터넷에 올리기

### 컴퓨터가 있다면 (5분, 회원가입 없이)

1. 컴퓨터 브라우저로 https://app.netlify.com/drop 접속
2. 압축을 푼 폴더(파일 7개)를 페이지 위로 끌어다 놓기
3. `https://무작위이름.netlify.app` 주소가 나옵니다. 이게 앱 주소입니다
4. 무료 계정을 만들면 주소를 `haru-내이름.netlify.app`으로 바꾸고 계속 보관할 수 있습니다

### 아이폰만 있다면 (GitHub Pages, 10분)

1. 파일 앱에서 `haru-pwa.zip`을 눌러 압축 풀기
2. 사파리로 https://github.com 접속 → 무료 가입 → 로그인
3. 오른쪽 위 `+` → **New repository** → 이름 `haru` → **Public** 선택 → Create
4. 만들어진 페이지에서 **uploading an existing file** 링크 누르기
5. **choose your files** → 파일 앱 → 압축 푼 폴더 → 파일 7개를 모두 선택 (폴더가 아니라 파일들을 골라야 합니다)
6. 아래 **Commit changes** 누르기
7. 위쪽 **Settings** → 왼쪽 메뉴 **Pages** → Branch를 `main`, 폴더는 `/ (root)`로 두고 **Save**
8. 1~2분 뒤 그 페이지에 `https://내아이디.github.io/haru/` 주소가 나옵니다

## 2단계 — 아이폰 홈 화면에 추가 (꼭 하세요)

1. **사파리로** 위 주소 열기 (크롬 말고 사파리여야 합니다)
2. 화면 아래 공유 버튼(↑) 누르기
3. 목록을 내려서 **홈 화면에 추가** → 추가
4. 이제부터는 **홈 화면 아이콘으로만** 여세요

홈 화면 아이콘으로 여는 것이 중요합니다.

- 사파리 탭은 한동안 안 쓰면 iOS가 저장한 기록을 지울 수 있습니다. 홈 화면에 추가한 앱은 지우지 않습니다.
- 알림 권한도 홈 화면에 추가한 상태에서만 받을 수 있습니다.
- 사파리 탭에서 적은 기록과 홈 화면 앱의 기록은 서로 다른 칸에 저장됩니다. 사파리에서 이미 적어둔 게 있으면, 사파리에서 **백업 파일 내려받기** → 홈 화면 앱에서 **백업 파일 불러오기**로 옮기세요.

## 3단계 — 기록이 저장되는 곳

기록은 **그 기기 안에** 남습니다. 아이폰에서 적은 것과 컴퓨터에서 적은 것은 따로 쌓입니다.
기기를 옮기거나 만약을 대비할 때는 통계 탭 → 저장과 백업에서

- **백업 파일 내려받기** → 공유 창에서 파일 앱이나 아이클라우드에 저장
- 다른 기기에서 **백업 파일 불러오기** → 그 파일 고르기

한 달에 한 번쯤 받아 두면 폰을 잃어버려도 기록은 남습니다.
두 기기가 자동으로 같아지게 하려면 서버(Supabase 무료 플랜 등)를 붙여야 합니다.

## 알림에 대해

- **앱 안 알림**: 루틴 탭 → 알림 켜기. 앱이 열려 있는 동안 설정한 시각에 배너와 소리, 그리고 폰 알림이 뜹니다.
- **앱을 닫아도 오는 알림**: 달력 탭 → **캘린더에 넘기기**를 누르면 공유 창이 뜹니다. **캘린더**를 고르고 **모든 캘린더에 추가**를 누르면, 일정·기간·장소·루틴 시각·목표 D-day가 알림까지 아이폰 캘린더로 들어갑니다. 이제 앱을 닫아도 아이폰이 알려 줍니다. 루틴이나 일정을 크게 바꿨을 때 다시 넘기면 됩니다.
- **앱에서 직접 오는 알림**: `SETUP.md` 의 3~7단계를 하면 알림 서버가 붙습니다. 그 뒤엔 앱을 완전히 닫아도 정해진 시각에 아이폰이 알려주고, 캘린더로 내보낼 필요가 없어집니다.

## 앱을 고칠 때

`index.html` 하나만 수정하면 됩니다. 수정한 뒤

1. `sw.js` 맨 위의 `const VERSION = 'haru-v1'` 을 `haru-v2`처럼 올리고
2. 파일을 다시 올리면(Netlify는 같은 자리에 다시 끌어다 놓기) 됩니다.

버전을 올리지 않으면 이전 화면이 캐시에서 계속 뜰 수 있습니다.
